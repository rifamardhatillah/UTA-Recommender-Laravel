# UTA-Recommender-Laravel
UTA Recommender adalah aplikasi Decision Support System (DSS) berbasis web yang dibangun menggunakan Laravel 12, dengan menerapkan metode UTA (UTilités Additives) untuk menyelesaikan permasalahan pengambilan keputusan. Aplikasi ini melakukan perhitungan ranking otomatis berdasarkan metode UTA, mengekspor hasil akhir dalam bentuk laporan PDF.
